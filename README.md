# HyperGuide

## About the Project

HyperGuide is a Django-based web application developed as my Bachelor of Computer Applications (BCA) academic project. The application was designed to simplify shopping inside hypermarkets by helping customers locate products, manage shopping lists, and view product information through a user-friendly interface.

## Features

* Product Search
* Shopping List Management
* Product Location Guidance
* Product Availability Tracking
* Loyalty Points Management
* User-Friendly Interface

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite

## Project Objective

The objective of HyperGuide is to improve the shopping experience by enabling customers to efficiently locate products, manage their shopping lists, and navigate large hypermarkets with ease.

## Project Status

This repository currently serves as a showcase of my academic project. The original source code is not available, but the project demonstrates my understanding of Django web development and database-driven application design.
